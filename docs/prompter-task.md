# Завдання для промптера — Wishlist, 4 екрани

**Джерела:** [spec.md](spec.md) (продукт), [style-guide.md](style-guide.md) (стиль **Ui**, shadcn/ui-подібний).
**Мета видачі:** статичні мокапи/промпти для генерації 4 екранів застосунку — кожен екран самостійний, без коду й без інтерактивної логіки.

## 0. Спільне для всіх екранів

**Стиль:** дизайн-система **Ui** — майже повністю ахроматична (Canvas `#f5f5f5`, Paper `#ffffff`, Ink `#0a0a0a`, Mid Gray `#737373`, hairline `#e5e5e5`), єдиний колір у системі — Ember `#e7000b`, і він зарезервований **виключно** для видалення. Ніде більше кольору не додавати.

**Шрифт:** Geist (сабститут — Inter). Заголовки — вага 600, tight tracking. Тексти — 400/500.

**Радіуси:** тільки 18px (кнопки/інпути/беджі) або 24px (картки). Нічого проміжного.

**Тіні:** лише на картках (hairline + тихий stack). У кнопок тіней немає.

**Тестові дані** (використовувати на всіх екранах зі списком):

| Емодзі | Назва | Ціна | Здійснено |
|---|---|---|---|
| 📚 | Книжка про дизайн | ₴450 | ні |
| ✈️ | Вихідні у Львові | ₴3 000 | ні |
| 🎧 | Навушники | ₴2 200 | **так** |

**Профіль для мокапів:** імʼя — «Марʼяна» (7 символів, проходить валідацію 3–15).

**Формат:** для кожного екрана згенерувати **desktop-версію** (сітка карток, max-width 1280px) і **mobile-версію** (одна колонка, кнопка «Додати» закріплена внизу).

---

## 1. Екран Init — знайомство

**Показується один раз**, до появи «Мої бажання». Мінімалістичний, по центру екрана.

**Елементи:**
- Заголовок: «Як тебе звати?» — Geist 600, display-розмір (48px десктоп / 30–36px мобільний).
- Одне текстове поле без лейбла або з лейблом «Твоє імʼя» — Input Field, `#f5f5f5`, radius 18px.
- Підказка під полем дрібним Mid Gray текстом: «Від 3 до 15 символів».
- Кнопка «Далі» — Primary Filled Button (`#0a0a0a`), **неактивна**, поки в полі менше 3 або більше 15 символів. Для мокапу показати активний стан із заповненим полем («Марʼяна»).

**Чого немає:** іншого контенту, навігації, логотипу — екран максимально порожній і сфокусований на одному питанні.

---

## 2. Екран «Мої бажання» — список

**Головний хаб.** Із нього — переходи на «Додати» і «Поділитися».

**Верхній блок:**
- Лічильник: «3 бажання · 1 здійснене» (з тестових даних) — Mid Gray, body-текст.
- Фільтр «Усі / Активні / Здійснені» — три Badge (Outline/Soft), поточний вибраний — Soft/Solid, інші — Outline. Для мокапу показати стан «Усі» вибраним.

**Сітка карток (desktop) / одна колонка (mobile):**
Кожна картка — Card (`#ffffff`, radius 24px, hairline-бордер, тихий shadow), всередині:
- Емодзі велике зверху (без картинки — тестові дані використовують тільки емодзі).
- Назва — body-lg, Ink.
- Ціна — body, Mid Gray.
- Посилання «Подивитися →» — маленьким текстом під ціною, Mid Gray.
- Кнопка «✓» у кутку картки — Outline Button, кругла/квадратна, позначає здійсненим.
- Іконка видалення (кошик) в іншому кутку — **єдине місце в макеті з кольором**, іконка Ember `#e7000b`.

**Картка здійсненого бажання** («🎧 Навушники»): та ж структура, але приглушена — нижча opacity, розташована **після** активних карток, кнопка «✓» у натиснутому/виділеному стані (не новий колір — просто інвертований Badge).

**Кнопка «Додати»:** Primary Filled Button. Desktop — у верхньому правому куті. Mobile — закріплена внизу екрана (fixed bar).

**Кнопка/дія «Поділитися»:** Outline або Secondary Ghost Button, поруч із «Додати».

**Окремо згенерувати порожній стан** (без жодного бажання): по центру текст «Поки що жодного бажання. Чого тобі хочеться?» + кнопка «Додати».

## 3. Екран «Додати» — форма

Коротка форма, по центру або на всю ширину мобільного екрана.

**Поля (у такому порядку):**
1. «Що це?» — Input Field, обовʼязкове, без значення в мокапі (placeholder) **або** із заповненим «Кава з собою» для показу активної кнопки — зробити два стани.
2. «Емодзі» — рядок із 6–8 популярних емодзі як вибір (🎁 📚 ✈️ 🎧 👟 💻 🎮 ☕), вибраний елемент виділений hairline-рамкою або Soft Badge фоном.
3. «Або своя картинка» — компактна зона завантаження файлу (dashed hairline border, radius 10px, іконка й підпис «Завантажити»).
4. «Скільки коштує» — Input Field для числа + select валюти (PLN / USD / EUR / UAH) поруч, той самий Input-стиль.
5. «Посилання» — Input Field, placeholder «https://…».

**Кнопка «Додати бажання»:** Primary Filled Button, на всю ширину або праворуч. Згенерувати **два стани**: неактивний (`#f5f5f5` фон, приглушений текст, назва порожня) і активний (`#0a0a0a`, назва заповнена).

**Навігація назад:** Ghost/Outline кнопка «← Скасувати» або іконка закриття зверху.

---

## 4. Екран «Поділитися» — вигляд для друзів

Той самий список, **без кнопок редагування, без видалення, без «✓»**. Здійснені бажання (🎧 Навушники) **не показувати**.

**Заголовок:** «Список бажань Марʼяни» — Geist 600, display-розмір (48px) — найбільший текст у всьому застосунку. Це основний спосіб виділити екран, оскільки декоративного кольору в системі немає.

**Картки:** спрощена версія Card — тільки емодзі, назва, ціна. Без посилання «Подивитися», без кнопок.

**Низ екрана — дві дії поруч:**
- «Поділитися» — Primary Filled Button.
- «Зберегти як картинку» — Outline Button.

**Мобільна версія:** та ж верстка в одну колонку; в описі варто позначити, що натискання «Поділитися» на телефоні викликає системне вікно шерингу (для мокапу достатньо самої кнопки, системний UI не малювати).

## 5. Припущення, якщо генератор про щось не запитає

Ці пункти в специфікації досі відкриті (див. [spec.md, розділ 10](spec.md#10-залишилися-відкритими)). Щоб не блокувати генерацію мокапів, за замовчуванням:

- Валюта в тестових даних і формі за замовчуванням — **UAH (₴)**.
- Сумарну вартість списку **не показувати**.
- Емодзі трактувати як типографічний елемент (глиф), а не як ілюстрацію — це не порушує заборону на «decorative graphics».
- Картинка бажання — просто зона завантаження файлу, без обмежень у мокапі.
- Імʼя після Init ніде не редагується — екранів налаштувань у макеті немає.

Якщо результат генерації буде використано для реальної розробки — ці припущення потрібно підтвердити окремо, вони позначені як відкриті питання, не як фінальні рішення.

## 6. Чого не генерувати

- Жодного п'ятого екрана чи модалки налаштувань.
- Жодного іншого кольору, крім Ember `#e7000b` на іконці видалення.
- Тіней на кнопках, бейджах або інпутах.
- Ілюстрацій, фото, декоративної графіки — тільки UI-компоненти й емодзі з тестових даних.
