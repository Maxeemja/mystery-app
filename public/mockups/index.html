Список бажань, яким приємно поділитися. Нижче — статичні мокапи чотирьох екранів: чистий HTML і CSS, без фреймворка й без збірки. Кожен стан відрендерено окремою секцією, тож нічого не треба клікати.

Екран 0 Init — знайомство Одне поле для імені, валідація 3–15 символів. Показується один раз. Відкрити → Екран 1 Мої бажання Сітка карток, лічильник, фільтр, позначка «здійснено» і видалення. Наповнений і порожній стан. Відкрити → Екран 2 Додати Коротка форма: назва, емодзі або картинка, ціна з валютою, посилання. Неактивна й активна кнопка. Відкрити → Екран 3 Поділитися Той самий список без кнопок редагування. Здійснені бажання приховані. Відкрити →

Дизайн-система Ui — майже повністю ахроматична. Єдиний колір у наборі — Ember #e7000b на іконці видалення. Радіуси лише 18px і 24px, тіні лише на картках. Специфікація продукту й повний style guide лежать у docs/.
